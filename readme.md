# Manga Trans

만화 이미지를 열고 **스페이스바 딱 한 번**만 누르면, 자동으로 한국어 번역이 그림 위에 딱 얹어지는 프로그램입니다.

어려운 설정 몰라도 됩니다. 이 문서에 나온 순서대로만 따라 하면 됩니다.

---

## 📌 이거 뭐 하는 프로그램인가요?

- 만화 이미지 파일을 여는 **뷰어(그림 보는 프로그램)** 입니다.
- 그런데 그냥 뷰어가 아니라, 버튼 하나만 누르면 **말풍선 안 글씨를 찾아서 한국어로 번역해 보여줍니다.**
- 사진 위에 바로 한글 번역이 덮어씌워지기 때문에, 따로 번역기를 켜서 복사·붙여넣기 할 필요가 없습니다.
- 일본어 외에 **중국어, 영어** 만화도 인식해서 번역할 수 있습니다.

---

## 🚀 일단 빨리 써보고 싶다면 (요약 3줄)

1. 아래 [다운로드](#️-다운로드) 항목에서 프로그램 받기
2. 컴퓨터에 **일본어 언어팩** 설치 (아래에서 설명함, 이거 안 하면 아예 작동 안 함)
3. 프로그램에서 이미지 열고 **스페이스바** 누르기

이 3개만 하면 일단 기본 기능은 다 됩니다. 아래는 더 자세한 설명입니다.

---

## 1단계. 시작하기 전에 꼭 해야 하는 것: 일본어 언어팩 설치

이 프로그램은 글자를 읽어내는 데 **윈도우에 이미 들어있는 기능(OCR)** 을 사용합니다. 그런데 이 기능은 일본어 언어팩이 컴퓨터에 깔려있어야만 작동합니다. 이걸 안 깔면 프로그램을 켜도 번역이 아예 안 됩니다.

**따라 하는 법**

1. 키보드에서 윈도우 키를 누르고 `설정`을 클릭합니다.
2. `시간 및 언어`를 클릭합니다.
3. `언어`를 클릭합니다.
4. `언어 추가` 버튼을 누릅니다.
5. 목록에서 `일본어`를 찾아 클릭하고 설치합니다.

> 이미 일본어 언어팩이 깔려있는 컴퓨터라면 이 단계는 그냥 넘어가도 됩니다.

이것만 해도 기본 번역 기능은 바로 사용할 수 있습니다.

---

## 2단계. (선택) 번역 품질을 더 좋게 만들고 싶다면: RapidOCR

1단계까지만 해도 작동은 하는데, 솔직히 글자 인식이 그렇게 정확하지는 않습니다. 특히 만화체 폰트는 잘 못 읽어서 번역이 이상하게 나올 수 있습니다.

**RapidOCR**이라는 걸 추가로 설치하면, AI가 글자를 읽기 때문에 훨씬 정확해집니다. (체감상 2~3배 정도)
일본어뿐 아니라 중국어·영어 만화도 인식/번역할 수 있게 되었습니다.

### 설치 전에 꼭 알아야 할 것

- 이건 자동으로 설치되는 게 아니고, **파이썬(Python)이라는 프로그램이 컴퓨터에 먼저 깔려 있어야 합니다.**
- 설치할 때 인터넷에서 파일을 많이 받아야 해서 **용량이 3GB 정도** 필요하고, 압축 풀고 복사하는 과정까지 생각하면 **C드라이브에 10GB 정도 빈 공간**을 남겨두는 게 좋습니다.
- 인터넷 속도에 따라 다르지만 **최대 30분까지** 걸릴 수 있습니다. 화면이 멈춘 것처럼 보여도 그냥 기다리세요.
- v1.3.0부터는 이 패키지들이 프로그램 전용 가상환경 안에 설치됩니다. 그래서 v1.2.0 이전 버전에서 Manga-OCR을 이미 쓰고 계셨더라도, 업데이트 후 처음 켤 때 RapidOCR 관련 패키지가 새로 설치되는(사실상 재설치) 과정을 거치실 수 있습니다. 아직 다양한 환경에서 충분히 테스트해보지 못했으니, 설치 중 이상한 점이 있으면 아래 [문의 / 버그 제보](#-문의--버그-제보) 방법대로 알려주세요.

### 파이썬 설치하는 법

1. [파이썬 다운로드 페이지](https://www.python.org/downloads/)에 들어갑니다.
2. Python 3.8 버전 이상, 3.12 버전 이하 정도를 다운로드합니다. (너무 최신 버전은 오류가 날 수 있어서 이 범위를 추천합니다.)
3. 설치할 때 화면 아래쪽에 있는 **"Add python.exe to PATH"** 체크박스를 꼭 체크합니다. 이걸 체크 안 하면 나중에 프로그램이 파이썬을 못 찾습니다.
4. 나머지는 그냥 "다음", "설치" 눌러서 끝까지 진행합니다.

### RapidOCR 켜는 법

1. Manga Trans 프로그램을 켭니다.
2. 화면 아래쪽으로 마우스를 가져가면 조작 버튼들이 나옵니다. 거기서 톱니바퀴(⚙) 모양을 누릅니다. (이게 설정 버튼입니다.)
3. `번역 엔진 설정`으로 들어갑니다.
4. `RapidOCR`을 선택합니다.
5. 안내창이 뜨면 그대로 따라가면 자동으로 필요한 파일들을 다운로드합니다.

> 설치 중에 화면이 멈춘 것 같으면, 키보드에서 `F12`를 눌러보세요. 진행 상황을 알려주는 로그(기록)창이 뜹니다. 거기에 "Daemon 종료됨"이라는 문구가 없으면 아직 설치가 진행 중인 겁니다.

## 3단계. 실제로 번역해보기

**이게 진짜 전부입니다.**

1. 프로그램에서 만화 이미지를 엽니다.
2. 키보드에서 **스페이스바**를 누릅니다.
3. 끝입니다. 자동으로 말풍선을 찾아서 번역해줍니다.

### 알아두면 좋은 것

- 프로그램을 처음 켰을 땐 번역 기능이 **꺼져 있는 상태**입니다. 그냥 그림만 보고 싶을 때 컴퓨터 자원을 아끼기 위해서 그런 것이니, 스페이스바를 눌러야 번역이 시작됩니다.
- RapidOCR을 쓰는 경우, 맨 처음 켤 때는 AI 모델을 불러오느라 1분 정도 걸릴 수 있습니다. 하지만 그 다음부터는 페이지 넘길 때마다 빠르게 번역됩니다.
- 한 번 번역한 페이지는 저장되기 때문에, 같은 페이지를 다시 열어도 또 번역하지 않고 바로 불러옵니다.
- 화면 좌측 상단에 지금 보고 있는 페이지와, 번역이 어디까지 진행됐는지 표시해주는 기능이 있습니다. 필요 없다면 설정에서 끌 수 있습니다.

### 자주 쓰는 버튼 / 마우스 동작

| 이 키(동작)를 누르면 | 이렇게 됩니다 |
| --- | --- |
| `F5` | 지금 보고 있는 이 페이지만 번역을 다시 합니다 |
| `Ctrl` + `F5` | 이 폴더 안에 있는 모든 페이지의 번역을 싹 다 다시 합니다 |
| 말풍선을 **더블클릭** | 번역 문장을 내가 직접 손으로 고칠 수 있습니다 |
| 글씨가 없는 부분을 **마우스로 드래그** | 자동으로 못 찾은 대사를 그 자리에서 다시 찾아서 번역합니다 |
| 마우스 **휠** | 이전/다음 페이지로 넘어갑니다 (마우스 서브 버튼 4, 5번도 동일하게 동작) |
| **우클릭 + 휠** | 이미지를 확대/축소합니다 |
| 말풍선을 **드래그해서 회전** | 기울어진 말풍선에 맞게 번역 텍스트를 직접 회전시킬 수 있습니다 (자동 인식이 아니라 직접 돌리는 방식입니다) |

## 4단계. (선택) 압축파일이나 인터넷 링크로도 열 수 있어요

- **압축파일(zip, cbz)**: 압축을 안 풀어도 됩니다. 그냥 프로그램 화면에 압축파일을 마우스로 끌어다 놓거나(드래그 앤 드롭), 파일 열기로 불러오면 바로 이미지들을 볼 수 있습니다. 번역도 똑같이 됩니다.
- **인터넷 링크(URL)**: 게시물 주소를 붙여넣으면 그 페이지 안에 있는 이미지들을 알아서 찾아옵니다.
  - 다만 어떤 이미지가 진짜 만화인지 자동으로 완벽하게 구분하지는 못해서, `설정 → 웹 크롤러 설정 → 만화 판정 최소 이미지 해상도` 에서 "이 크기보다 작은 이미지는 무시해라" 하는 기준을 정해줘야 정확도가 올라갑니다.
  - 클릭해서 넘겨봐야 하는 방식의 사이트(예: 히토미 같은 곳)는 아직 지원 안 됩니다.
- **다음 페이지 미리 번역하기**: 설정에서 "몇 페이지 앞까지 미리 번역해둘지" 숫자를 정할 수 있습니다. 숫자를 크게 잡으면 다음 페이지들도 미리 번역해둬서 넘길 때 기다릴 필요가 없어지는데, 클라우드 번역(아래 6단계)을 쓰는 경우엔 그만큼 API 사용량(=돈)이 늘어날 수 있으니 주의하세요.

## 5단계. (선택) 번역된 페이지를 이미지로 저장하기

번역이 끝난 페이지를 그림 파일로 따로 저장해두고 싶다면 내보내기 기능을 쓰면 됩니다.

- 원본 이미지와 같은 크기 그대로 **PNG 파일**로 저장됩니다.
- 저장할 위치(폴더)는 내가 원하는 곳으로 직접 지정할 수 있습니다.

## 6단계. (선택) 어떤 번역기를 쓸지 고르기

기본으로 구글 번역이 들어가 있지만, 다른 걸로 바꿀 수도 있습니다. 표로 정리하면 이렇습니다.

| 이름 | 한 줄 설명 | 이런 사람한테 추천 |
| --- | --- | --- |
| 구글 번역 | 기본으로 들어있음, 그냥 쓰면 됨 | 아무 설정도 하기 싫은 사람 |
| ezTrans | 내 컴퓨터 안에서 번역 처리 | ezTrans를 이미 갖고 있는 사람 |
| Ollama (로컬 AI) | 내 컴퓨터의 AI로 번역, 돈 안 듦 | 컴퓨터 성능이 좋고, 돈 쓰기 싫은 사람 |
| 클라우드 AI (Gemini / Claude / GPT 등) | 인터넷에 있는 AI한테 물어봐서 번역, 문맥을 잘 이해함 | 번역 품질을 제일 중요하게 생각하는 사람 |

### Ollama(로컬 AI) 쓰는 법

1. 먼저 [Ollama 홈페이지](https://ollama.com/)에서 Ollama를 직접 설치합니다. (Manga Trans가 자동으로 설치해주지 않습니다.)
2. 원하는 AI 모델을 Ollama로 미리 받아둡니다.
3. Manga Trans 설정에서 `Ollama` 선택
4. 주소는 기본값(`http://localhost:11434/v1`) 그대로 두면 됩니다.
5. 모델 이름은 명령 프롬프트(cmd)에 `ollama list`라고 치면 나오는 이름을 그대로 복사해서 넣습니다.

### 클라우드 AI(Gemini, Claude, GPT 등) 쓰는 법

1. Manga Trans 설정에서 원하는 AI 모델을 선택합니다.
2. 그 AI 회사 홈페이지(구글, OpenAI 등)에 직접 가입해서 **API 키**라는 걸 발급받습니다.
3. 발급받은 키를 설정 화면에 붙여넣습니다.
4. 끝입니다.

> 참고: OpenAI 호환 형식을 지원하는 무료/저가형 서비스(예: NVIDIA NIM)도 "OpenAI Compatible" 항목으로 연결해서 쓸 수 있습니다. nvidia가 아닌 다른 OpenAI 호환 서비스를 쓸 때 오류가 나던 문제는 v1.3.0에서 수정되었습니다.

## ❗ 설치나 실행이 안 될 때 (문제 해결)

### OCR 엔진(구 Manga-OCR, 현재 RapidOCR) 관련 데몬이 예기치 않게 종료됐다는 오류가 뜰 때

최신 그래픽카드(RTX 40/50 시리즈)나 AMD 그래픽카드를 쓰는 컴퓨터에서 종종 발생합니다.

1. 키보드에서 윈도우 키를 누르고 `cmd`라고 쳐서 명령 프롬프트를 엽니다.
2. 아래 문장을 그대로 복사해서 붙여넣고 엔터를 누릅니다.

```bash
python -m pip install "transformers<5.0.0" sentencepiece protobuf tiktoken --force-reinstall
```

3. 설치가 끝나면 Manga Trans를 다시 실행해서, 잘 되길 기도합시다.

그래도 안 되면:

1. 프로그램에서 `F12`를 눌러 로그(기록) 창을 엽니다.
2. `설정 → 시스템 환경 진단 → 진단 리포트 생성 및 복사`를 눌러 진단 내용을 복사합니다.
3. 위 두 가지(로그 내용 + 진단 리포트)를 [이슈](https://github.com/izure1/manga-trans/issues)로 남겨주시면 확인하겠습니다.

### "Python이 설치되어 있지 않습니다"라는 메시지가 계속 뜰 때

파이썬은 설치했는데 이 메시지가 계속 뜬다면, 설치할 때 **PATH 등록**을 안 했을 가능성이 큽니다.

1. 명령 프롬프트(cmd)를 열고 `python --version`이라고 쳐봅니다.
2. 버전 번호가 나오면 정상, 아무 반응이 없거나 오류가 나면 파이썬을 삭제 후 다시 설치하면서 **"Add python.exe to PATH"** 체크박스를 꼭 체크해주세요.
